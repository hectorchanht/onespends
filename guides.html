匯入教學：將你嘅購物記錄帶入嚟

All your spends in one place — just need a glance.

你啲消費記錄散喺唔同平台度，唔使逐筆手打。以下逐個平台教你點樣拎返出嚟，再匯入 OneSpends。

通用原則：三種檔案都食

  • CSV — 銀行、信用卡、支付 app 匯出嘅明細表。
  • JSON — 有啲工具／平台俾嘅訂單資料檔。
  • HTML — 平台冇匯出功能嗰陣，將訂單記錄頁面成個存落嚟就得（下面 Buyee、Jauce 就係咁做）。

三種檔案都係喺你部裝置嘅瀏覽器入面解析，檔案唔會上載去任何 server。匯入嗰陣，OneSpends 會按「日期 + 金額 + 商戶」跳過重複記錄，匯完會話你知新增咗幾多筆、跳過咗幾多筆。

如果檔案入面冇寫明貨幣，匯入之前可以喺 App 撳 ⬆ 匯入，喺「匯入貨幣」度揀定（例如日本平台揀 JPY）；揀「自動」嘅話，HTML 匯入預設當日圓，CSV / JSON 預設當港幣。

Buyee：訂單記錄點匯入

  1. 用電腦瀏覽器登入 Buyee，去 My Page → Order History（購入履歴）。
  2. 喺訂單記錄頁面撳 Ctrl+S（Mac 係 Cmd+S），將成個網頁另存為 HTML 檔（儲存格式揀「網頁」嗰種就得）。
  3. 如果記錄有分頁，逐頁開、逐頁重複上一步存檔 — 一頁一個 HTML 檔。
  4. 返嚟 OneSpends 主頁，撳「⬆ 匯入檔案」，揀返啱啱存落嚟嘅 .html 檔（有幾多個分頁檔就匯入幾多次）。
  5. 匯入之前，將「匯入貨幣」揀做 JPY（或者用「自動」，HTML 預設都係日圓）。
  6. 睇下匯入結果訊息，再去 dashboard 核對金額同商品名。

老實講：Buyee 冇提供一鍵將訂單記錄匯出做 CSV / JSON 嘅掣，所以先要用「儲存網頁」呢招。頁面上面嘅金額係日圓。

Jauce：訂單記錄點匯入

  1. 用電腦瀏覽器登入 Jauce，去 My Account 入面嘅 order / won history（你買過、落札成功嘅記錄頁）。
  2. 喺記錄頁面撳 Ctrl+S（Mac 係 Cmd+S），將成個網頁另存為 HTML 檔。
  3. 如果記錄有分頁，逐頁開、逐頁重複上一步存檔。
  4. 返嚟 OneSpends 主頁，撳「⬆ 匯入檔案」，揀返個 .html 檔。
  5. 匯入之前，將「匯入貨幣」揀做 JPY（或者用「自動」，HTML 預設都係日圓）。
  6. 睇下匯入結果訊息，再去 dashboard 核對 — OneSpends 會認頁面表格入面嘅日付、商品名同落札価格。

老實講：Jauce 一樣冇一鍵匯出訂單記錄做 CSV / JSON 嘅掣，所以要用「儲存網頁」呢招。頁面上面嘅金額係日圓。

其他平台：有 CSV / JSON 就直接匯入

銀行、信用卡或者支付 app 如果有「匯出 CSV」「下載明細」之類嘅功能，匯出完直接喺 OneSpends 主頁撳「⬆ 匯入檔案」揀個檔就得，唔使改任何嘢。OneSpends 認以下欄位（中文、英文、日文 header 都認）：

  • 日期：日期 / date / 日付
  • 金額：金額 / amount / 価格 / 合計 / 落札価格
  • 商戶：商戶 / vendor / 商品 / 商品名 / description
  • 幣別：幣別 / currency / 通貨（寫 ¥ 或 円 會當日圓、HK$ 當港幣、NT$ 當台幣、US$ 當美金）

JSON 檔都一樣：一個訂單一個 object，欄位名用上面嗰啲（或者 orderDate、price、title 呢啲常見名）就認到；成個檔係一個 array，或者用 orders / items / results 包住個 array 都得。

如果個平台完全冇得匯出？

仲有最後一招：影相。訂單確認電郵、收貨單、紙本收據，影低用 OneSpends 嘅收據 OCR 入數，一樣喺你部機完成。點做睇 產品導覽 第 2 步「影一張相」。
